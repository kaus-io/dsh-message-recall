### DSH Message Recall

![language-typescript](https://img.shields.io/badge/language-typescript-orange.svg) ![dsh-plugin](https://img.shields.io/badge/dsh-plugin-4D6BFE)

### 介绍

`DSH Message Recall` 为 DeepSeek Harness Web 的已发送用户消息增加「撤回」按钮。确认后，在目标消息之前分叉出新会话，并把原文放回输入框，修改后即可重新发送；旧会话保留并尝试自动归档。适合修正提问或调整对话方向，无需手动复制文本，也不会抹掉历史记录或回滚已经执行的操作。
